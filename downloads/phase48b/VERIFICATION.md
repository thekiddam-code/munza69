Actual Windows render-device output, physical headphone/private-loopback isolation, Sonar/microphone survival, Samsung hardware/native APK, TV, Tailscale routing and antivirus scans were unavailable. No physical audio or device result is claimed. Live public Myinstants metadata was inspected; actual copyrighted audio was not downloaded or bundled. Import conversion was exercised with owned WAV/MP3 fixtures; user-permitted live audio still needs a manual check. Other browser codecs may be unsupported. No new game-chat mixer/voice calibration/loudness normalization is implemented. Full historical/campaign matrix was not repeated.

Limits: 64 clips / 64 MiB, 30s each, canonical 24kHz mono PCM16; original compressed uploads not separately kept. One host clip at a time. Offline private preview requires a loaded/reachable UMBRA shell and cached audio; host playback requires the server. Device identity changes require reselection; pathological driver cleanup can require server restart. Already-downloaded terminal copies cannot be remotely erased; clear/prune that dedicated cache. Corrupt libraries are reported, never reset.

## Update safely

Export a full voyage backup and retain the old installation. Stop the server and close authoritative tabs. Extract separately; preserve private companion configuration. Keep the same browser profile/hostname/port; run Start_Remote_Deck.bat and explicitly ENTER after readiness. Do not clear IndexedDB or writer locks. No ICARUS migration/reset is introduced. On later B upgrades copy **the entire soundboard_data directory while stopped**; it is separate from voyage backups and deliberately absent from Git/ZIP. For rollback, export a post-update voyage backup, stop this build and use the retained earlier folder/origin; keep the private sound library and both backups separately.

Before trusting private preview, use headphones on the terminal and verify that output is not captured by existing Sonar/OBS/game-chat routes. UMBRA does not silently modify those routes. Follow the exact hardware checklist in the validation document. The screenshot gallery is actual Chromium UI with owned generated audio/output fixtures; it is not a physical Samsung/Alienware audio certification.

# Phase 4.1 static security notes

The server retains existing trusted-LAN HTTP on 0.0.0.0:8765, PIN pairing with hashed tokens, same-Origin JSON POST checks and bounded bodies. Authenticated desktop/game actions remain intentionally powerful PyAutoGUI operations; do not expose this port publicly. Local IP discovery uses UDP route selection to 192.0.2.1:80 without application payload. Optional configured private-TV WSS:8002 retains inherited ssl.CERT_NONE; LAN impersonation remains a risk. The original TV allowlist and managed volatile power-off timer remain. Dependencies are unchanged; this is not a hashed transitive vulnerability audit.

New host bootstrap releases the dedicated key only to validated local-PC requests (loopback hostname/IP, or literal local IP matching peer and socket). Remote and URL-encoded/dot-path simulation requests are normalized and redirected. Other host routes need the key, instance and generation. Paired remote SSE/dispatch use bearer auth; no world-save upload endpoint exists. GET streams are finite with an eight-second socket timeout and recheck token validity. Requests/queue/receipt/body/frame bounds prevent unlimited history growth in these structures; this is not a broad denial-of-service certification.

Client source includes same-origin fetch/SSE, AbortController timeouts, localStorage UI preferences and sessionStorage ownership/receipt IDs. Request UUID has an insecure-LAN-browser fallback; this is a uniqueness identifier, never the authentication secret. No arbitrary command strings/eval/shell editor, external service calls by game agents, new cloud process, service installation, registry/firewall changes or antivirus disabling. The launcher now opens the local host guide using standard Python webbrowser; the batch launcher itself is unchanged. Browser client/server writes remain local; private config/pairing/TV tokens are excluded from packaging and must be retained privately during upgrade.

Static hashes/syntax/endpoint tests are not antivirus, penetration or physical hardware certification. The original native app is not modified. Native build/security review awaits recovered source. Existing Tailscale routing remains user-managed and unverified physically; no public forwarding is configured here.

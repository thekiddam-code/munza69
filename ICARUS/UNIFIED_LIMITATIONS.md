# Remaining scope and verification limits

This is a tested Phase 1 implementation increment. The complete uploaded specification is **not** certified complete.

- Calendar pacing, approved/recognized dates, real-week boundaries, monotonic physical state and bounded recovery are implemented. Timezone/week-crossing and rollback policies are explicit in UNIFIED_ARCHITECTURE.md. Six hours is a deliberate offline catch-up cap; longer gaps are logged rather than simulated.
- Full-moon atmosphere uses an approximate Earth mean synodic cycle from a reference epoch, with an approximately one-day window. It is not a verified astronomical ephemeris. October/Friday-13th/lunar flags affect presentation only. Rich authored seasonal dialogue/pacing is not complete.
- Personal observances are explicitly configured per crew, with voluntary acknowledgment during existing provisioned meals. Automatic religious calendar conversion, authored personal traditions, birthdays inferred from unavailable history and a decoration art library are not implemented.
- The four environments reuse the existing ship/asteroid/derelict state, including the military region on the asteroid. There is no full new independent warship renderer or fully merged physical coordinate engine for all historic grids. Detailed near-core content and temporal behavior remain existing/creator-reference work, not newly claimed simulations.
- Spatial camera/cutaway occupancy is corrected and wheelchair navigation respects lift availability. Natural character animation, body silhouettes, anatomical prosthetics, wheelchair artwork and final android locomotion are not complete. Current locomotion badges and traversal modifiers are functional initial support, not final visuals.
- Initial adult/egg state and causal host development exist, with seeded access risk and recorded injury/death. Full creature autonomy/hunting/ecology, elaborate variants and parasite-specific medical options are incomplete. The initial registry guarantee does not retroactively delete legacy entities in older saves.
- Lore reference and acquired archive separation exists. Unified military observations represent actual expedition knowledge, but radio-delivery timing is not yet unified with the legacy field relay queue. Individual knowledge and secrecy across all old UI views need further review.
- Objects support initial ownership, carriage, placement, gifts, memorial retention and feasible inheritance. Full prop physics and recovery of objects from every possible corridor/field position remain incomplete. Widget resize dimensions are not persisted.
- As in the inherited runtime, the pause button is a session control: an ordinary application restart begins unpaused. Calendar cursors and physical state persist, and bounded catch-up rules apply. Persisting the captain’s paused UI state remains follow-up work.
- Physical Windows/Android/TV, Firefox/Safari, real desktop-input devices, hostile concurrent tabs, real network interruptions and sustained human story/UX review are untested. Large JSON backups remain memory intensive. This batch does not replace the previous year-long results with an invented new 365-day run; current real-calendar campaign durations are stated exactly in reports.

Recommended next batch: finish the existing unified-world foundations—radio/individual-knowledge delivery, exact astronomical dates or an offline ephemeris, authored individual observances, accessible character/prop art and animation, and complete creature behavior with adverse tests—before adding new locations or unrelated systems.

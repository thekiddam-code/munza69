- **Gym deferred by explicit user choice.** A03 remains Observation Lounge; A09 alone becomes Crew Lounge. No gym/exercise/rehabilitation/fitness benefit is claimed. Both original IDs/doors/cameras remain.
- New art is active in detailed primary/preview/field/reconstruction cameras. Optional classic schematic and existing Sunday timeline/film presentation retain their own representations; this is not a complete audiovisual/cinematic asset replacement.

Turning is side-view heading/pose change, not3D anatomy. Facial/wardrobe/posture variations are persistent but limited. Human aesthetic/accessibility review remains a release gate.
- Room geometry remains an abstract graph and layered side view. Lounge/table/bunk approach/seat/rise is real saved task progress; critical operational work retains the existing station controller and coarse anchor. No full collision mesh, furniture avoidance for every legacy task, measured door widths, physical chair dimensions or certified wheelchair turning-radius model. Decorative art does not become an invisible obstacle. Existing ladder/lift/accessibility gates are regression-tested within those abstractions.
- Quarters now have recognizable bunks/lockers through existing restricted feeds, but per-berth ownership and personalized belongings are not modeled; those details are not fabricated from unknown private history.
- Not every decorative appliance or crate is a simulated usable resource. No new working rover/forklift/coffee source, fake instrument values, unseen security footage or manufactured damage is presented as a feature. Console graphics show generic operational UI marks, not invented measured data.
- Appearance derives stable defaults for legacy saves and labeled reconstructions. There is no new appearance editor. Existing supported saved descriptors/body/mobility persist; old historical states without them cannot recreate unknowable original details. Authentic original video is still unavailable; source-state reconstruction labels remain.
- Boot reports actual stages but does not make large synchronous parse/schema work magically instantaneous. Worker-based parsing/streaming is deferred. Very large saves can still block the browser briefly. The whole historical archive still grows with genuine events; new bounded visual/task metadata does not solve arbitrary-duration retention.

- Physical Windows laptop, Samsung phone/Tab S5e/TV, native APK, real LAN/Tailscale, human GPU/touch/accessibility and antivirus scans cannot be performed here. Linux Chromium HTTP/emulation/visual checks are not physical hardware certification. No antivirus is disabled.

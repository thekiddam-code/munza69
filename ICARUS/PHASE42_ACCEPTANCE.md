# Living Ship acceptance and final-release boundary

The approved scope is PHASE42_LIVING_SHIP_PLAN.md. This build integrates stages A–F into the established simulation. PHASE42_VALIDATION.md records actual executions and campaign measurements; statements below refer to automated evidence, not a physical/human sign-off.

| Criterion | Implementation / verification |
|---|---|
| Persistent daily routines and meaningful completion | Role shifts, needs/preferences, adopted budgets and source-linked actual repair completion; deterministic activity and full-engine tests |
| Visible activity matches physical work/location | Existing physical travel/capacity/supplies retained; disabled states, task motions, sustained cleanup and camera view-purity tests |
| Relationships develop through actual interaction | Gradual typed bonds, private sourced memories, actual same-role experience and mutual adult consent; no default couples |
| Memory affects future choices | Remembered encounter locations bias reachable routine choices; established experience/caution still affects work/mission willingness |
| Plausible gossip and correction | Actual co-location, acquired shareable premise, no private transmission; separate uncertain claim; all Runtime receipt channels review original evidence |
| Causal incidents and consequences, quiet periods | Existing incident/dependency policies preserved; local debris cleanup, actual blocked-work requests and policy-based relief; quiet component/adverse full-engine tests |
| SOL observational limitations | Private state excluded from Bridge/UMBRA; only genuine source facts/reports, explicit claim/inference labels; privacy and source audits |
| Existing saves and weekly continuity | Additive migration; genuine complete Phase 4.1 donor plus existing legacy/weekly/active-operation tests and checkpoint reloads |
| UMBRA observes the sole authoritative world | Preserved authority/security/telemetry; host/remote HTTP/browser, deduplication, pairing, disconnect and phone/tablet emulation |
| Scale and long-running stability | Source-validated 100-registered/20-active fixture, bounded recent lists, component benchmark and accelerated campaigns; no assertion of 100 active actors |
| Authentic Sunday material | Existing source-checked snapshots/films retained; actual completion/social/help records plus independent full-history source audit; no scripted weekly plot or guaranteed lethal footage |

Human judgment of believable personalities, visual polish and sustained entertainment remains necessary. Physical Windows/Android/TV/antivirus and native-project recovery gates are unverified. Detailed social dialogue, workforce activation/recruitment, procedural art polish and deeper observed assistance workflows remain refinement work. These are explicit boundaries, not hidden completed features. ICARUS is not declared a finished final-release game.

# Phase 3 static security review

Phase 3 adds readable local JavaScript crew, camera, SOL-template and timeline modules. They contain no network calls, host command execution, dynamic code evaluation or system modifications. Simulation agents cannot invoke host actions. The Python host, configuration, runtime requirements and Windows BAT are unchanged from validated Phase 2. Static source review and file hashes support these claims; they are not antivirus certification. All newly displayed event/name text is HTML-escaped before timeline/commentary insertion.

## Security-relevant retained behavior

- `Start_Remote_Deck.bat` changes to its own directory, uses `where py`, runs local `py server.py` or `python server.py`, then pauses on exit. It performs no elevation, hidden install, startup registration, firewall or antivirus changes. The optional documented pip command installs the unchanged runtime dependencies into the selected Python environment; the launcher itself does not install packages.
- `server.py` is an intended remote-control application. PyAutoGUI can send real keyboard/mouse/text actions to the currently focused host application. Configured macros can affect clipboard/game/application state. Fail-safe and release timers remain; they do not prevent a malicious paired device from issuing allowed commands.
- The host listens on `0.0.0.0:8765` over plain HTTP. Pairing PIN, hashed bearer-token storage, startup host key, Origin/body/command validation and finite queues remain. Traffic is not TLS-encrypted; this is a trusted-LAN service, not an Internet-hardened endpoint. No firewall rules are created by the package.
- Optional Samsung control uses a configured private IPv4 destination at WSS port 8002. The inherited `ssl.CERT_NONE` disables peer-certificate validation for TV compatibility; LAN impersonation remains a risk. This is documented inherited behavior, not an antivirus exception.
- The local-address discovery UDP `connect` to `192.0.2.1:80` selects a route/address; that function sends no application payload. Browser simulation/Android traffic uses the existing same-origin `/api` bridge. Simulation agents cannot issue real commands or network requests.
- Expected host writes are configuration, paired-token hashes, optional TV address/token and their atomic temporary replacements. Browser IndexedDB/local/session storage and user-requested backup downloads are additional writes. Generated device/TV credential files are excluded from the ZIP. No service, scheduled task, registry change, driver or antivirus exclusion is installed.
- Core saves retain private canon, individual records and full world history. Captain/debug views and exported backups can inspect them; individual knowledge is a game mechanic, not multi-user confidentiality. Imports still validate schema before restoring state. Large/hostile input parsing and concurrent writers need further hardening.
- Python requirements remain version ranges, not a hashed transitive lockfile: PyAutoGUI, psutil and websocket-client. Their entire dependency chain was not independently vulnerability-audited. LZ-String's existing license is preserved. Astronomy Engine is vendored without modification and does not require runtime network access.

## Verification limits

This review covers source behavior and source/package identity, not an antivirus certification or penetration test. `clamscan` was unavailable; Windows Defender and physical Windows execution were unavailable. No antivirus engine scan is claimed. No antivirus, Safe Browsing or other protection was disabled, circumvented or recommended for bypass. A SHA-256 checksum proves artifact identity, not that every security risk is absent.

The ordinary source ZIP has transparent compression, readable files, no executable wrapper and no obfuscation. Lite excludes standalone test runners, reports, development tools and packaging scripts, but retains the diagnostic assets/test-mode code loaded by the application. Functional tests distinguish actual HTTP/Chromium execution from stubbed physical input/TV sockets and mobile emulation. PHASE2_VALIDATION.md reports actual results and unavailable checks.

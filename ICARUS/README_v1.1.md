# ICARUS v1.1 — The Continuous Voyage

Keep the complete web directory together. This version adds local voyage, discovery, team and economy modules alongside the existing ship UI and systems.

On Windows, install the existing runtime dependencies (`py -m pip install -r requirements.txt`), run Start_Remote_Deck.bat, and open the printed ICARUS PC URL. Export an old-version backup before upgrading. Saves remain specific to browser origin and port.

Weekly episodes now archive the story without resetting the world. The ship clock, damage, incidents, equipment, resources, crew, treatment, research and expeditions continue. The explicitly confirmed New Voyage control starts a fresh scenario and reloads normal initialization.

Remote expedition panels show teams, scientific programs and independently supported conclusions. Supplies show voyage stores and SOL's priority mode. Existing captain explain/recall/abort/command/release controls remain. Field specimens emerge from seeded exploration rather than acceptance-test injection.

Read ENGINEERING_v1.1.md for the changelog, architecture, save migration, economy model and test commands. KNOWN_LIMITATIONS_v1.1.md documents model limits and the next batch. The packaged reports directory includes baseline, unit, adverse, seven-day, thirty-day, ninety-day, resource/discovery statistics and validation summary files. BUILD_MANIFEST.json identifies the source commit and file hashes.

Only a completed passing ninety-day report establishes this build's acceptance demonstration. Intermediate or interrupted reports are not passes. Physical-device integrations are not certified by the browser simulation tests.

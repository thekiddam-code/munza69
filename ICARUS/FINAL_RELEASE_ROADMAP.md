## Next core milestones, in order

1. Finish the existing Unified World foundations: individual-knowledge/radio delivery, verified lunar dates, authored observances, accessible body/prop animation and creature behavior with adverse coverage. Preserve existing spatial/source/state authority.
2. Review the v1.4.1 compound-failure and long-duration evidence before extending recovery policy. Retain finite paid work, actual physical access, bounded engineer reservations and meaningful unrecoverable emergencies; widen seed and failure-combination coverage. Review small ore-harvest batching and expedition overhead using the recorded finite returns, without changing the core scope.
3. Review actual v1.4 stories for specificity, repetition and believable crew participation; enrich existing categories and responses, without new map or economic systems.
4. Consolidate Operations, crew, research and chronicle navigation; add accessible focus/keyboard behavior and test real tablet/Windows layouts.
5. Improve source-grounded weekly selection and concise SOL interpretation; retain quiet episodes and unresolved threads.
6. Stream large backups/history, enforce single-writer ownership, improve recovery explanations and test actual target hardware.
7. Run broader balance campaigns plus sustained human playtests; then define an audio/cinematic accessibility budget and a final-release candidate checklist.

Each batch must update evidence, status and remaining gates. A completed test does not automatically change a partially implemented content or polish milestone to complete.

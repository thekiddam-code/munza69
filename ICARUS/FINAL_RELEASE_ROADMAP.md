# ICARUS — Final Release Roadmap

This roadmap follows FINAL_DESIGN.md. Status is about demonstrated behavior, not aspiration. v1.4 is an integration/refinement batch, not a declaration of final release.

Status vocabulary: **Complete and verified**, **Implemented but needing refinement**, **Partially implemented**, **Not started**, **Deferred to the Extended Universe edition**.

| Milestone | Current status | Evidence / remaining release gate |
| --- | --- | --- |
| Core simulation completeness | Implemented but needing refinement | Continuous crew/ship/science/resource/mission loop and bounded local context exist. Final v1.4 reports verify their tested seeds; more balance and compound-failure play review remain. |
| Anthology storytelling completeness | Partially implemented | Causal beginnings, development, pauses, overlapping threads, actual consequences and open endings work. The interaction vocabulary is deliberately small; deepen contextual specificity and evaluate long-session interest before adding scope. |
| Crew autonomy and relationship depth | Implemented but needing refinement | Existing personality/physical autonomy plus source-backed shared experiences, trust, medical recovery and traditions. Numeric models need richer characterization and human review; avoid repetitive liaison/relationship framing. |
| Scientific and Lazarus systems | Implemented but needing refinement | Existing custody/evidence/experiment/replication/resource rules retained; narrative questions follow actual results. Improve scientific explanation and pacing. No guaranteed Lazarus success or final story ending. |
| SOL operational behavior | Implemented but needing refinement | Safety, maintenance, local authorization, reserve priority and explainable refusals operate autonomously. Broader adverse balancing and better concise operational explanations remain. |
| SOL narrative behavior | Partially implemented | Source-bounded observations, uncertainty and occasional dry corporate commentary. More varied, individual-aware interpretation needs authored/content review, without fictitious events. |
| Core vs Extended Universe separation | Complete and verified | Independent v1.3 branch/ZIP and recovery instructions; default core freezes legacy sectors and uses bounded local venues and a separate save namespace. Deterministic and browser tests cover the boundary. |
| User interface and visual polish | Partially implemented | Operations overview now combines local context and developing stories in existing visual language; touch/command tests cover key paths. Specialist views still reflect historical layering. Full navigation/accessibility/visual consistency pass remains. |
| Sunday chronicles | Implemented but needing refinement | Source-backed cards, tones, open threads and strict lethal-selection provenance. Selection variety, stronger human-readable episode organization and character focus need review. |
| Audio and cinematic presentation | Not started | No new audio score, authored camera montage or final cinematic pipeline is claimed. Existing source-labeled replays/cards remain. Define optional sound/motion/accessibility before implementation. |
| Save reliability and performance | Implemented but needing refinement | Isolated core namespace, transactional snapshots, history/export/recovery and explicit v1.3 import are tested. Large saves still need streamed/incremental processing; physical devices and hostile multi-tab writers are unverified. |
| Gameplay balance and testing | Partially implemented | Deterministic regressions, adverse conditions, multi-seed campaigns and measured diversity. Broader seed coverage, physical devices, long-form human playtesting and interest/repetition evaluation remain. |
| Final release readiness | Not started | Release candidate requires the definition of done, onboarding, packaging, platform checks and sustained human play review. Automated success alone cannot close this milestone. |
| Procedural planetary / galaxy expansion | Deferred to the Extended Universe edition | Preserved v1.3; inactive in core. |
| Territorial factions / galactic economy | Deferred to the Extended Universe edition | Preserved policies/economy in independent archive; no core territorial or galactic growth. |

## Next core milestones, in order

1. Review actual v1.4 stories for specificity, repetition and believable crew participation; enrich existing categories and responses, without new map or economic systems.
2. Consolidate Operations, crew, research and chronicle navigation; add accessible focus/keyboard behavior and test real tablet/Windows layouts.
3. Improve source-grounded weekly selection and concise SOL interpretation; retain quiet episodes and unresolved threads.
4. Stream large backups/history, enforce single-writer ownership, improve recovery explanations and test actual target hardware.
5. Run broader balance campaigns plus sustained human playtests; then define an audio/cinematic accessibility budget and a final-release candidate checklist.

Each batch must update evidence, status and remaining gates. A completed test does not automatically change a partially implemented content or polish milestone to complete.

Use the same browser, profile and PC address as your existing voyage. Browser saves belong to that address. Changing between localhost, 127.0.0.1 and a LAN IP cannot automatically move an existing save.

Before upgrading, export a complete backup from the previous build. Keep the old folder and private pairing files. Close old simulation tabs before opening the updated host.

Open UMBRA remote terminal instead

The phone/tablet uses UMBRA. It never starts the ship simulation. The server does not upload, replace or merge voyage saves.

# UMBRA // Weyland-Yutani Arcade Kill Cam

Six **original, offline-bundled, 8-bit pixel-art animated GIFs** for UMBRA's optional **Corporate Anomalies > Arcade Kill Cam** feature.

These are **fictional arcade animations**, not ICARUS gameplay recordings or real Legendary Kill Cam footage.

- Format: GIF89a, 128 × 72 px, 12 frames, 240 ms per frame (2.88 s), loop, no sound.
- All files are local and require no internet or external fonts/icons.
- These compact pixel animations are distinct from the separately generated higher-resolution **Vent Ambush concept preview** shared in ChatGPT. The preview was not automatically available to the GitHub connector; the bundled GIFs are original lightweight versions suitable for a first implementation.
- UMBRA UI must clearly label the category **FICTIONAL ARCADE** and distinguish it from future actual ICARUS gameplay capture.
- Both Corporate Anomalies and Arcade Kill Cam toggles default **OFF**. Manual preview/gallery remains available.
- No flashing/strobing, fake emergency alerts, automatic TV commands or ICARUS simulation side effects.
- Respect reduced-motion preferences by showing a static frame instead of autoplay.
- Integrate using `manifest.json`; the assets are not automatically wired into the Android app until Codex locates the actual UMBRA app source and implements the gallery.

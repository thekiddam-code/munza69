# ICARUS Phase 4.9 — Living Specimens & Frontier Encounters

This is an integrated, bounded biological-life release over the existing voyage. Three authored appearance/behavior families inhabit finite local habitats on asteroid 8847-A: small crawlers, light-responsive colonies, and defensive segmented crawlers. Labels remain provisional observations. No specimen is placed aboard merely to populate a camera. Quiet campaigns are valid.

Autonomous qualified crew prepare supplies at C04, travel, inspect, tend, repair or recover. Care uses finite food/water/lab supplies; repairs use parts/tools. Recovery can fail or lose contact. Successful recapture uses actual equipment and physical return to containment. Deceased specimens can be physically archived at B10 while retaining research identity.

## Limits and tradeoffs

This is three lightweight biological families, not a reproductive food-web simulator. At most four collected subjects occupy the current care capacity; deceased specimens must be physically archived to free fixtures. Additional chambers, invasive experiment choreography and new capture hardware are not supplied. Previously declined specimens can be investigated again through a new explicitly targeted inspection/sampling mission; depleted habitats do not regenerate rewards.

Recovery currently performs room-local searches/capture. Field container recovery uses the inherited body-position model’s recorded node; precise mid-passage dropped-container trajectories/salvage are not modeled or verified. Within-room pixel placement is coarse, rather than a measured collision or anchoring model. It does not implement continuous interception of an organism mid-corridor, full collision physics, ventilation-duct networks or a tactical combat system. A missing specimen can remain unresolved. Enclosure failure does not guarantee escape, injury or death. Initial Xenomorph/egg identities and causal prerequisites are preserved; this batch does not activate them for drama.

The rendered organisms are procedural pixel art based on authoritative state. They are not physical camera footage. Newly retained specimen snapshots are available only when existing camera capture selected the actual room; the system does not reconstruct omitted historical specimen images as genuine captures. Physical Windows/Samsung/TV/native APK/antivirus testing and human art/story review are not certified by browser fixtures. Native APK rebuilding remains pending original source recovery.

UMBRA soundboard/audio code and external routing are unchanged. The user reported Fortnite voice working through VoiceMeeter → Sonar Microphone; combined effects/private-preview/close/crash checks remain separate and pending. Keep VoiceMeeter/Sonar configuration independent of this game update.

## Rollback

Keep both pre- and post-upgrade backups. Older builds do not understand the new species policies and must not advance a post-4.9 world: they can misinterpret these organisms as legacy predators. There is no automatic downgrade converter.

Stop this build and all host tabs. To use the previous release, use a separate browser profile and import the **pre-4.9 full voyage backup** before resuming. Keep the current profile and post-4.9 world untouched for returning to this build. Restore the private soundboard_data folder independently; its schema is unchanged. Do not delete the current browser database or attempt to remove biological records manually.

Actual tests, campaign measurements, source lineage and unavailable gates are in PHASE49_VALIDATION.md and the published verification directory. Passing tests is not a declaration that ICARUS is a finished game.
